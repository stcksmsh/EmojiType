Try it

Same rules as the extension, rebuilt for this page. Nothing leaves your browser.

    1. :keyword: replaces it with the emoji.
    2. :key + Tab autocompletes. ↑ ↓ pick, Enter inserts.
    3. Backspace right after an emoji gives the keyword back.

    The dictionary

    The 27 keywords EmojiType ships with. Click one to type it into the playground. In the extension you add, edit and remove your own, and back them up.

    Three tabs in the popup

    Whitelist or blacklist sites by URL pattern, so EmojiType runs only where you want it. Turn it on or off for the current site with one click.

    Set the delimiter (:, ;, …), switch suggestions on or off and set their opacity, and pick a light or dark theme.

    Add, edit and remove keyword → emoji entries. Backup exports or imports your dictionary, or resets it to the defaults.

    Install

    For Chrome and Edge (Manifest V3).

    1. Get the source: clone the repository or download the latest release.
    2. Open chrome://extensions and turn on Developer mode.
    3. Click Load unpacked and pick the folder that contains manifest.json.
    4. Pin it, choose a delimiter, start typing.

    Private by default

    EmojiType collects nothing and sends nothing: no analytics, no third-party services. The text is replaced locally, in the page you're typing on. Privacy policy
